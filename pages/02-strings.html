Reversing Strings

Q1. Reverse a string. (Asked multiple times, including "without using StringBuilder" and "using recursion" variants.)
LeetCode: Reverse String ↗

Problem statement: Given a string, return a new string containing the same characters in reverse order. Example: reverseUsingBuilder("hello") should return "olleh".

Using StringBuilder (simplest, idiomatic solution)

public class StringReverser {
 
    public static String reverseUsingBuilder(String inputText) {
        return new StringBuilder(inputText).reverse().toString();
    }
 
    public static void main(String[] arguments) {
        System.out.println(reverseUsingBuilder("hello")); // "olleh"
    }
}

Without using StringBuilder (manual two-pointer swap)

public class StringReverser {
 
    // Converts the string to a character array, then swaps characters from
    // opposite ends moving inward -- avoids relying on StringBuilder.reverse()
    public static String reverseWithoutBuilder(String inputText) {
        char[] characterArray = inputText.toCharArray();
        int leftIndex = 0;
        int rightIndex = characterArray.length - 1;
 
        while (leftIndex < rightIndex) {
            char temporaryCharacter = characterArray[leftIndex];
            characterArray[leftIndex] = characterArray[rightIndex];
            characterArray[rightIndex] = temporaryCharacter;
            leftIndex++;
            rightIndex--;
        }
        return new String(characterArray);
    }
 
    public static void main(String[] arguments) {
        System.out.println(reverseWithoutBuilder("hello")); // "olleh"
    }
}

Using recursion

public class StringReverser {
 
    // Recursively reverses a string: the reverse of "firstChar + rest" is
    // "reverse(rest) + firstChar"
    public static String reverseUsingRecursion(String inputText) {
        if (inputText.isEmpty() || inputText.length() == 1) {
            return inputText; // base case: an empty or single-character string is its own reverse
        }
        char firstCharacter = inputText.charAt(0);
        String remainingCharacters = inputText.substring(1);
 
        // reverse everything AFTER the first character, then append the
        // first character onto the very end
        return reverseUsingRecursion(remainingCharacters) + firstCharacter;
    }
 
    public static void main(String[] arguments) {
        System.out.println(reverseUsingRecursion("hello")); // "olleh"
    }
}

Complexity: O(n) time for the StringBuilder and manual-swap versions, O(1) extra space beyond the result (the manual-swap version reverses in place on the character array). The recursive version is O(n) time but O(n) extra space, due to both the call-stack depth and the fact that String concatenation at each recursive step creates new String objects.

Q2. Reverse the order of words in a sentence.
LeetCode: Reverse Words In A String ↗

Problem statement: Given a sentence, reverse the ORDER of its words (not the characters within each word). Example: reverseWordOrder("The quick brown fox") should return "fox brown quick The".

public class SentenceWordReverser {
 
    public static String reverseWordOrder(String inputSentence) {
        // split on one-or-more whitespace characters, so extra spaces don't
        // produce empty "words" in the result
        String[] individualWords = inputSentence.trim().split("\\s+");
 
        StringBuilder reversedSentenceBuilder = new StringBuilder();
        for (int wordIndex = individualWords.length - 1; wordIndex >= 0; wordIndex--) {
            reversedSentenceBuilder.append(individualWords[wordIndex]);
            if (wordIndex > 0) {
                reversedSentenceBuilder.append(" ");
            }
        }
        return reversedSentenceBuilder.toString();
    }
 
    public static void main(String[] arguments) {
        System.out.println(reverseWordOrder("The quick brown fox"));
        // "fox brown quick The"
    }
}

Complexity: O(n) time, where n is the total length of the sentence. O(n) extra space for the word array and the result.

Q3. Reverse each word in a sentence and connect them using "-".
LeetCode: Reverse Words In A String Iii ↗

Problem statement: Given a sentence, reverse the CHARACTERS within each individual word (keeping the word order unchanged), then join the resulting words together using a hyphen ("-") instead of spaces. Example: reverseEachWordAndJoin("The quick brown") should return "ehT-kciuq-nworb".

public class WordCharacterReverser {
 
    public static String reverseEachWordAndJoin(String inputSentence) {
        String[] individualWords = inputSentence.trim().split("\\s+");
        StringBuilder resultBuilder = new StringBuilder();
 
        for (int wordIndex = 0; wordIndex < individualWords.length; wordIndex++) {
            String reversedWord = new StringBuilder(individualWords[wordIndex]).reverse().toString();
            resultBuilder.append(reversedWord);
            if (wordIndex < individualWords.length - 1) {
                resultBuilder.append("-");
            }
        }
        return resultBuilder.toString();
    }
 
    public static void main(String[] arguments) {
        System.out.println(reverseEachWordAndJoin("The quick brown"));
        // "ehT-kciuq-nworb"
    }
}

String Compression & Transformation

Q4. String compression. (Asked multiple times, including a HackerRank variant.)
LeetCode: String Compression ↗

Problem statement: Given a string, compress consecutive runs of the same character by replacing each run with the character followed by the count of its consecutive occurrences. If the compressed string is not shorter than the original, return the original string unchanged. Example: compressRepeatingCharacters("aabcccccaaa") should return "a2b1c5a3", since that is shorter than the 11-character original.

public class StringCompressor {
 
    public static String compressRepeatingCharacters(String inputText) {
        if (inputText == null || inputText.isEmpty()) {
            return inputText;
        }
 
        StringBuilder compressedBuilder = new StringBuilder();
        int runStartIndex = 0;
 
        while (runStartIndex < inputText.length()) {
            char currentCharacter = inputText.charAt(runStartIndex);
            int runEndIndex = runStartIndex;
 
            // extend runEndIndex forward while the SAME character continues to repeat
            while (runEndIndex < inputText.length() && inputText.charAt(runEndIndex) == currentCharacter) {
                runEndIndex++;
            }
 
            int runLength = runEndIndex - runStartIndex;
            compressedBuilder.append(currentCharacter).append(runLength);
 
            runStartIndex = runEndIndex; // jump ahead to the start of the NEXT run
        }
 
        String compressedResult = compressedBuilder.toString();
        // only use the compressed form if it's actually SHORTER than the original
        return compressedResult.length() < inputText.length() ? compressedResult : inputText;
    }
 
    public static void main(String[] arguments) {
        System.out.println(compressRepeatingCharacters("aabcccccaaa")); // "a2b1c5a3"
        System.out.println(compressRepeatingCharacters("abcdef"));      // "abcdef" (compression not shorter)
    }
}

Complexity: O(n) time (a single pass through the string), O(n) extra space for the compressed result in the worst case.

Q5. Capitalize each word in a sentence.
LeetCode: Related: Capitalize The Title ↗

Problem statement: Given a sentence, return a new sentence where the first letter of every word is capitalized, and the remaining letters of each word are lowercase. Example: capitalizeEachWord("the QUICK brown fox") should return "The Quick Brown Fox".

public class SentenceCapitalizer {
 
    public static String capitalizeEachWord(String inputSentence) {
        String[] individualWords = inputSentence.trim().split("\\s+");
        StringBuilder capitalizedBuilder = new StringBuilder();
 
        for (int wordIndex = 0; wordIndex < individualWords.length; wordIndex++) {
            String currentWord = individualWords[wordIndex];
            if (!currentWord.isEmpty()) {
                // uppercase the first character, lowercase everything after it
                String capitalizedWord = Character.toUpperCase(currentWord.charAt(0))
                    + currentWord.substring(1).toLowerCase();
                capitalizedBuilder.append(capitalizedWord);
            }
            if (wordIndex < individualWords.length - 1) {
                capitalizedBuilder.append(" ");
            }
        }
        return capitalizedBuilder.toString();
    }
 
    public static void main(String[] arguments) {
        System.out.println(capitalizeEachWord("the QUICK brown fox"));
        // "The Quick Brown Fox"
    }
}

Q6. Rotate a string (and: given two strings, determine whether one is a rotation of the other).
LeetCode: Rotate String ↗

Problem statement: Given a string and a number of positions, produce the string rotated LEFT by that many positions. Additionally, given two strings, determine whether the SECOND is a rotation of the FIRST. Examples: rotateStringLeft("abcdef", 2) should return "cdefab". isRotationOfOther("waterbottle", "erbottlewat") should return true.

public class StringRotator {
 
    // Rotates inputText LEFT by rotationCount positions
    public static String rotateStringLeft(String inputText, int rotationCount) {
        if (inputText.isEmpty()) {
            return inputText;
        }
        // normalize the rotation count in case it's larger than the string's length
        int normalizedRotationCount = rotationCount % inputText.length();
 
        String movedToFront = inputText.substring(normalizedRotationCount);
        String movedToBack = inputText.substring(0, normalizedRotationCount);
        return movedToFront + movedToBack;
    }
 
    // Determines whether candidateRotation is a rotation of originalText.
    // Trick: any rotation of originalText is always a SUBSTRING of
    // (originalText + originalText) -- concatenating the string with itself
    // covers every possible rotation point.
    public static boolean isRotationOfOther(String originalText, String candidateRotation) {
        if (originalText.length() != candidateRotation.length()) {
            return false;
        }
        String doubledOriginalText = originalText + originalText;
        return doubledOriginalText.contains(candidateRotation);
    }
 
    public static void main(String[] arguments) {
        System.out.println(rotateStringLeft("abcdef", 2)); // "cdefab"
        System.out.println(isRotationOfOther("waterbottle", "erbottlewat")); // true
        System.out.println(isRotationOfOther("waterbottle", "bottlewatern")); // false
    }
}

Complexity: O(n) time and space for rotateStringLeft. O(n) time and space for isRotationOfOther, where the doubled-string trick avoids needing to manually check every possible rotation point one at a time.

Searching, Parsing & Counting

Q7. Count the occurrences of a substring within a string. (Asked multiple times in the original list.)

Problem statement: Given a source string and a target substring, count how many times the target substring appears within the source string. Example: countSubstringOccurrences("ababababab", "aba") should return 2 if OVERLAPPING occurrences are counted (matches starting at index 0 and index 4), or the count can also be computed for non-overlapping occurrences depending on the exact requirement -- both variants are shown below.

public class SubstringOccurrenceCounter {
 
    // Counts OVERLAPPING occurrences -- after finding a match, the search
    // resumes from just ONE position past where the match started
    public static int countOverlappingOccurrences(String sourceText, String targetSubstring) {
        if (targetSubstring.isEmpty()) {
            return 0;
        }
        int occurrenceCount = 0;
        int searchStartIndex = 0;
 
        while (true) {
            int foundIndex = sourceText.indexOf(targetSubstring, searchStartIndex);
            if (foundIndex == -1) {
                break; // no more occurrences found
            }
            occurrenceCount++;
            searchStartIndex = foundIndex + 1; // advance by only ONE position (allows overlap)
        }
        return occurrenceCount;
    }
 
    // Counts NON-overlapping occurrences -- after finding a match, the search
    // resumes AFTER the entire matched substring
    public static int countNonOverlappingOccurrences(String sourceText, String targetSubstring) {
        if (targetSubstring.isEmpty()) {
            return 0;
        }
        int occurrenceCount = 0;
        int searchStartIndex = 0;
 
        while (true) {
            int foundIndex = sourceText.indexOf(targetSubstring, searchStartIndex);
            if (foundIndex == -1) {
                break;
            }
            occurrenceCount++;
            searchStartIndex = foundIndex + targetSubstring.length(); // skip past the whole match
        }
        return occurrenceCount;
    }
 
    public static void main(String[] arguments) {
        System.out.println(countOverlappingOccurrences("ababababab", "aba"));    // 4
        System.out.println(countNonOverlappingOccurrences("ababababab", "aba")); // 2
    }
}

Complexity: O(n*m) time in the worst case, where n is the length of the source string and m is the length of the target substring (this is the complexity of Java's built-in String.indexOf implementation for typical inputs). More advanced algorithms like Knuth-Morris-Pratt (KMP) can guarantee O(n + m) time, but are rarely required for a typical interview answer unless specifically asked for.

Q8. Check whether parentheses/curly braces/brackets are balanced. (Asked as two separate questions in the original list.)
LeetCode: Valid Parentheses ↗

Problem statement: Given a string containing only the characters (, ), {, }, [, and ], determine whether every opening bracket has a matching closing bracket of the SAME type, in the correct nested order. Example: areBracketsBalanced("{[()()]}") should return true. areBracketsBalanced("{[(])}") should return false (the brackets are present in equal numbers, but not correctly NESTED).

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Map;
 
public class BracketBalanceChecker {
 
    // Maps each closing bracket to its required matching opening bracket
    private static final Map<Character, Character> MATCHING_OPENING_BRACKET = Map.of(
        ')', '(',
        '}', '{',
        ']', '['
    );
 
    public static boolean areBracketsBalanced(String inputText) {
        Deque<Character> openBracketStack = new ArrayDeque<>();
 
        for (char currentCharacter : inputText.toCharArray()) {
            if (currentCharacter == '(' || currentCharacter == '{' || currentCharacter == '[') {
                openBracketStack.push(currentCharacter); // remember this opening bracket
 
            } else if (MATCHING_OPENING_BRACKET.containsKey(currentCharacter)) {
                // this is a closing bracket -- it must match the MOST RECENT
                // unmatched opening bracket (last in, first out)
                if (openBracketStack.isEmpty()
                        || openBracketStack.pop() != MATCHING_OPENING_BRACKET.get(currentCharacter)) {
                    return false; // no matching opener, or the wrong TYPE of opener
                }
            }
            // any other character is simply ignored
        }
 
        // balanced only if every opening bracket found its match
        return openBracketStack.isEmpty();
    }
 
    public static void main(String[] arguments) {
        System.out.println(areBracketsBalanced("{[()()]}")); // true
        System.out.println(areBracketsBalanced("{[(])}"));   // false -- incorrectly nested
        System.out.println(areBracketsBalanced("((("));       // false -- unmatched openers
    }
}

Complexity: O(n) time (a single pass through the string), O(n) extra space for the stack in the worst case (e.g. a string of all opening brackets).

Q9. Parse a string of numbers and return it as an integer.
LeetCode: String To Integer Atoi ↗

Problem statement: Given a string representing a valid integer (e.g. "12345" or "-42"), convert it to its integer value WITHOUT using the built-in Integer.parseInt() method.

public class StringToIntegerParser {
 
    public static int parseStringToInteger(String numericText) {
        int currentIndex = 0;
        boolean isNegativeNumber = false;
 
        // handle an optional leading sign character
        if (numericText.charAt(0) == '-' || numericText.charAt(0) == '+') {
            isNegativeNumber = numericText.charAt(0) == '-';
            currentIndex = 1;
        }
 
        int parsedValue = 0;
        while (currentIndex < numericText.length()) {
            char currentDigitCharacter = numericText.charAt(currentIndex);
            if (currentDigitCharacter < '0' || currentDigitCharacter > '9') {
                throw new NumberFormatException("Invalid character in numeric string: " + currentDigitCharacter);
            }
            int digitValue = currentDigitCharacter - '0'; // converts the character to its numeric value
            parsedValue = parsedValue * 10 + digitValue;
            currentIndex++;
        }
 
        return isNegativeNumber ? -parsedValue : parsedValue;
    }
 
    public static void main(String[] arguments) {
        System.out.println(parseStringToInteger("12345")); // 12345
        System.out.println(parseStringToInteger("-42"));   // -42
    }
}

Complexity: O(n) time, where n is the number of digits. O(1) extra space.

Q10. Sort words in a string array according to their sizes.
LeetCode: Rearrange Words In A Sentence ↗

Problem statement: Given an array of words, sort them by LENGTH (shortest to longest). Example: sortWordsBySize(new String[]{"banana", "kiwi", "apple", "fig"}) should return ["fig", "kiwi", "apple", "banana"].

import java.util.Arrays;
import java.util.Comparator;
 
public class WordSizeSorter {
 
    public static String[] sortWordsBySize(String[] wordArray) {
        String[] sortedWords = wordArray.clone(); // avoid mutating the caller's original array
        Arrays.sort(sortedWords, Comparator.comparingInt(String::length));
        return sortedWords;
    }
 
    public static void main(String[] arguments) {
        String[] wordArray = {"banana", "kiwi", "apple", "fig"};
        String[] sortedResult = sortWordsBySize(wordArray);
        System.out.println(Arrays.toString(sortedResult));
        // [fig, kiwi, apple, banana]
    }
}

Complexity: O(n log n) time, where n is the number of words, due to the underlying comparison-based sort.

Q11. Find the second most used alphabet (letter) in a sentence.

Problem statement: Given a sentence, determine which letter appears the SECOND most frequently. Example: findSecondMostFrequentLetter("programming") should identify the letter with the second-highest frequency count among all letters in the text.

import java.util.HashMap;
import java.util.Map;
 
public class SecondMostFrequentLetterFinder {
 
    public static char findSecondMostFrequentLetter(String inputSentence) {
        Map<Character, Integer> letterFrequencyMap = new HashMap<>();
 
        // count occurrences of each letter, ignoring case and non-letter characters
        for (char currentCharacter : inputSentence.toLowerCase().toCharArray()) {
            if (Character.isLetter(currentCharacter)) {
                letterFrequencyMap.merge(currentCharacter, 1, Integer::sum);
            }
        }
 
        char mostFrequentLetter = ' ';
        char secondMostFrequentLetter = ' ';
        int highestFrequencyCount = 0;
        int secondHighestFrequencyCount = 0;
 
        for (Map.Entry<Character, Integer> currentEntry : letterFrequencyMap.entrySet()) {
            int currentFrequency = currentEntry.getValue();
            char currentLetter = currentEntry.getKey();
 
            if (currentFrequency > highestFrequencyCount) {
                // current letter becomes the new MOST frequent;
                // the PREVIOUS most-frequent letter becomes the new second-most-frequent
                secondHighestFrequencyCount = highestFrequencyCount;
                secondMostFrequentLetter = mostFrequentLetter;
                highestFrequencyCount = currentFrequency;
                mostFrequentLetter = currentLetter;
            } else if (currentFrequency > secondHighestFrequencyCount) {
                secondHighestFrequencyCount = currentFrequency;
                secondMostFrequentLetter = currentLetter;
            }
        }
        return secondMostFrequentLetter;
    }
 
    public static void main(String[] arguments) {
        System.out.println(findSecondMostFrequentLetter("programming"));
        // 'r' or 'g' (both appear twice; 'm' appears twice as well -- ties are
        // broken by HashMap iteration order, which is not guaranteed)
    }
}
Note: When frequencies tie, the specific letter returned depends on HashMap's iteration order, which is not guaranteed to be consistent. If a well-defined tie-break rule is required (e.g. alphabetically first among tied letters), sort the frequency entries explicitly rather than relying on map iteration order.

Complexity: O(n) time to build the frequency map, O(k) time to scan it for the top two frequencies, where k is the number of distinct letters (at most 26). Overall O(n) time.

Q12. Given numbers in postfix (Reverse Polish) notation, evaluate the result.
LeetCode: Evaluate Reverse Polish Notation ↗

Problem statement: Postfix notation places operators AFTER their operands (e.g. "3 4 +" means 3 + 4). Given a postfix expression as a space-separated string, evaluate it and return the numeric result. Example: evaluatePostfixExpression("5 1 2 + 4 * + 3 -") should return 14.

import java.util.ArrayDeque;
import java.util.Deque;
 
public class PostfixExpressionEvaluator {
 
    public static int evaluatePostfixExpression(String postfixExpression) {
        Deque<Integer> operandStack = new ArrayDeque<>();
        String[] expressionTokens = postfixExpression.trim().split("\\s+");
 
        for (String currentToken : expressionTokens) {
            if (isArithmeticOperator(currentToken)) {
                // an operator applies to the TWO most recently pushed operands
                int secondOperand = operandStack.pop();
                int firstOperand = operandStack.pop();
                int operationResult = applyOperator(firstOperand, secondOperand, currentToken);
                operandStack.push(operationResult);
            } else {
                operandStack.push(Integer.parseInt(currentToken));
            }
        }
        return operandStack.pop(); // the final remaining value is the answer
    }
 
    private static boolean isArithmeticOperator(String token) {
        return token.equals("+") || token.equals("-") || token.equals("*") || token.equals("/");
    }
 
    private static int applyOperator(int firstOperand, int secondOperand, String operatorSymbol) {
        switch (operatorSymbol) {
            case "+": return firstOperand + secondOperand;
            case "-": return firstOperand - secondOperand;
            case "*": return firstOperand * secondOperand;
            case "/": return firstOperand / secondOperand;
            default: throw new IllegalArgumentException("Unknown operator: " + operatorSymbol);
        }
    }
 
    public static void main(String[] arguments) {
        System.out.println(evaluatePostfixExpression("5 1 2 + 4 * + 3 -")); // 14
        // Step by step: 1 2 + = 3; 3 4 * = 12; 5 12 + = 17; 17 3 - = 14
    }
}

Complexity: O(n) time, where n is the number of tokens in the expression. O(n) extra space for the operand stack in the worst case.

Anagrams & Word Comparison

Q13. Check whether two words (or strings) are anagrams of each other.
LeetCode: Valid Anagram ↗

Problem statement: Two strings are anagrams of each other if one can be formed by rearranging the letters of the other, using every letter exactly once. Given two strings, determine whether they are anagrams. Example: areAnagrams("listen", "silent") should return true.

import java.util.Arrays;
 
public class AnagramChecker {
 
    // Approach 1: sort both strings' characters and compare -- simple and clear
    public static boolean areAnagramsUsingSort(String firstWord, String secondWord) {
        if (firstWord.length() != secondWord.length()) {
            return false;
        }
        char[] firstCharacters = firstWord.toLowerCase().toCharArray();
        char[] secondCharacters = secondWord.toLowerCase().toCharArray();
 
        Arrays.sort(firstCharacters);
        Arrays.sort(secondCharacters);
 
        return Arrays.equals(firstCharacters, secondCharacters);
    }
 
    // Approach 2: frequency counting -- faster (O(n) instead of O(n log n))
    public static boolean areAnagramsUsingFrequencyCount(String firstWord, String secondWord) {
        if (firstWord.length() != secondWord.length()) {
            return false;
        }
        int[] letterFrequencyCounts = new int[26]; // assumes lowercase English letters only
 
        for (int index = 0; index < firstWord.length(); index++) {
            letterFrequencyCounts[Character.toLowerCase(firstWord.charAt(index)) - 'a']++;
            letterFrequencyCounts[Character.toLowerCase(secondWord.charAt(index)) - 'a']--;
        }
 
        // if the two words are true anagrams, every count returns to exactly zero
        for (int currentCount : letterFrequencyCounts) {
            if (currentCount != 0) {
                return false;
            }
        }
        return true;
    }
 
    public static void main(String[] arguments) {
        System.out.println(areAnagramsUsingFrequencyCount("listen", "silent")); // true
        System.out.println(areAnagramsUsingFrequencyCount("hello", "world"));   // false
    }
}

Complexity: the sort-based approach is O(n log n) time. The frequency-count approach is O(n) time, O(1) extra space (since the frequency array has a fixed size of 26, independent of the input length).

Q14. Find the shortest distance ("midpoint") between two words in a document.
LeetCode: Shortest Word Distance ↗

Problem statement: Given a large body of text and two distinct target words that both appear somewhere within it, find the SMALLEST distance (measured in number of words apart) between any occurrence of the first word and any occurrence of the second word. Example: given the words ["the", "quick", "fox", "jumped", "over", "the", "lazy", "fox"], the shortest distance between "fox" and "the" is 1 (the "fox" at index 2 is adjacent to nothing useful, but the "the" at index 5 is 2 words from the "fox" at index 7 -- the true minimum distance across all pairs of occurrences is computed by the algorithm below).

public class ShortestWordDistanceFinder {
 
    public static int findShortestDistanceBetweenWords(String[] documentWords,
                                                         String firstTargetWord,
                                                         String secondTargetWord) {
        int lastSeenIndexOfFirstWord = -1;
        int lastSeenIndexOfSecondWord = -1;
        int shortestDistanceFound = Integer.MAX_VALUE;
 
        // single pass through the document: whenever EITHER target word is
        // seen, immediately check the distance to the most recent sighting
        // of the OTHER target word
        for (int currentIndex = 0; currentIndex < documentWords.length; currentIndex++) {
            String currentWord = documentWords[currentIndex];
 
            if (currentWord.equals(firstTargetWord)) {
                lastSeenIndexOfFirstWord = currentIndex;
            } else if (currentWord.equals(secondTargetWord)) {
                lastSeenIndexOfSecondWord = currentIndex;
            }
 
            // only compute a distance once BOTH words have been seen at least once
            if (lastSeenIndexOfFirstWord != -1 && lastSeenIndexOfSecondWord != -1) {
                int currentDistance = Math.abs(lastSeenIndexOfFirstWord - lastSeenIndexOfSecondWord);
                shortestDistanceFound = Math.min(shortestDistanceFound, currentDistance);
            }
        }
        return shortestDistanceFound;
    }
 
    public static void main(String[] arguments) {
        String[] documentWords = {"the", "quick", "fox", "jumped", "over", "the", "lazy", "fox"};
        int shortestDistance = findShortestDistanceBetweenWords(documentWords, "fox", "the");
        System.out.println(shortestDistance);
        // The closest pair is "the" at index 5 and "fox" at index 7, giving a distance of 2 --
        // closer than the alternative pairing of "fox" at index 2 with "the" at index 0 or 5.
    }
}

Complexity: O(n) time — a single pass through the document, tracking only the most recent sighting of each target word — rather than the O(n^2) brute-force approach of comparing every occurrence of the first word against every occurrence of the second word.

String Dynamic Programming

Q15. Given two strings, return the length of their longest common subsequence.
LeetCode: Longest Common Subsequence ↗

Problem statement: A subsequence is a sequence of characters that appear in the same relative order within a string, but not necessarily contiguously. Given two strings firstText and secondText, find the length of their LONGEST common subsequence. Example: findLongestCommonSubsequenceLength("abcde", "ace") should return 3, since "ace" is a subsequence of both.

public class LongestCommonSubsequenceFinder {
 
    public static int findLongestCommonSubsequenceLength(String firstText, String secondText) {
        int firstLength = firstText.length();
        int secondLength = secondText.length();
 
        // matchTable[i][j] = length of the longest common subsequence using
        // the first i characters of firstText and the first j characters of secondText
        int[][] matchTable = new int[firstLength + 1][secondLength + 1];
 
        for (int firstIndex = 1; firstIndex <= firstLength; firstIndex++) {
            for (int secondIndex = 1; secondIndex <= secondLength; secondIndex++) {
                if (firstText.charAt(firstIndex - 1) == secondText.charAt(secondIndex - 1)) {
                    // characters match -- extend the subsequence found without these characters
                    matchTable[firstIndex][secondIndex] = matchTable[firstIndex - 1][secondIndex - 1] + 1;
                } else {
                    // characters differ -- take the best result from skipping
                    // one character from EITHER string
                    matchTable[firstIndex][secondIndex] = Math.max(
                        matchTable[firstIndex - 1][secondIndex],
                        matchTable[firstIndex][secondIndex - 1]);
                }
            }
        }
        return matchTable[firstLength][secondLength];
    }
 
    public static void main(String[] arguments) {
        System.out.println(findLongestCommonSubsequenceLength("abcde", "ace")); // 3
    }
}

Complexity: O(firstLength x secondLength) time and space, using a standard 2D dynamic programming table.

Q16. Edit Distance: given two strings, find the minimum number of operations to convert one into the other.
LeetCode: Edit Distance ↗

Problem statement: Given two strings sourceWord and targetWord, find the minimum number of single-character INSERT, DELETE, or REPLACE operations required to transform sourceWord into targetWord (this is also known as the Levenshtein distance). Example: calculateEditDistance("horse", "ros") should return 3 (replace 'h' with 'r', remove 'r', remove 'e').

public class EditDistanceCalculator {
 
    public static int calculateEditDistance(String sourceWord, String targetWord) {
        int sourceLength = sourceWord.length();
        int targetLength = targetWord.length();
 
        // editTable[i][j] = minimum edit distance between the first i
        // characters of sourceWord and the first j characters of targetWord
        int[][] editTable = new int[sourceLength + 1][targetLength + 1];
 
        // base cases: transforming an empty string into a string of length j
        // requires exactly j insertions (and vice versa for deletions)
        for (int sourceIndex = 0; sourceIndex <= sourceLength; sourceIndex++) {
            editTable[sourceIndex][0] = sourceIndex;
        }
        for (int targetIndex = 0; targetIndex <= targetLength; targetIndex++) {
            editTable[0][targetIndex] = targetIndex;
        }
 
        for (int sourceIndex = 1; sourceIndex <= sourceLength; sourceIndex++) {
            for (int targetIndex = 1; targetIndex <= targetLength; targetIndex++) {
 
                if (sourceWord.charAt(sourceIndex - 1) == targetWord.charAt(targetIndex - 1)) {
                    // characters already match -- no operation needed here,
                    // carry forward the result from both strings one character shorter
                    editTable[sourceIndex][targetIndex] = editTable[sourceIndex - 1][targetIndex - 1];
                } else {
                    // characters differ -- try all three possible operations
                    // and take whichever leads to the fewest total edits
                    int deleteCost = editTable[sourceIndex - 1][targetIndex];       // delete from source
                    int insertCost = editTable[sourceIndex][targetIndex - 1];       // insert into source
                    int replaceCost = editTable[sourceIndex - 1][targetIndex - 1];  // replace a character
 
                    int cheapestOperationCost = Math.min(deleteCost, Math.min(insertCost, replaceCost));
                    editTable[sourceIndex][targetIndex] = cheapestOperationCost + 1;
                }
            }
        }
        return editTable[sourceLength][targetLength];
    }
 
    public static void main(String[] arguments) {
        System.out.println(calculateEditDistance("horse", "ros")); // 3
    }
}

Complexity: O(sourceLength x targetLength) time and space, using a standard 2D dynamic programming table analogous to the Longest Common Subsequence solution above.
