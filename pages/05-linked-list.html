Traversal & Basic Operations

Q1. Write a linked list traversal.

Problem statement: Given the head of a singly linked list, visit and print every node's value, from the head through to the end of the list.

public class LinkedListTraverser {
 
    public static void traverseAndPrintList(LinkedListNode headNode) {
        LinkedListNode currentNode = headNode;
 
        while (currentNode != null) {
            System.out.print(currentNode.nodeValue);
            if (currentNode.nextNode != null) {
                System.out.print(" -> ");
            }
            currentNode = currentNode.nextNode; // advance to the next node
        }
        System.out.println();
    }
 
    public static void main(String[] arguments) {
        LinkedListNode headNode = new LinkedListNode(1);
        headNode.nextNode = new LinkedListNode(2);
        headNode.nextNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode.nextNode = new LinkedListNode(4);
 
        traverseAndPrintList(headNode); // 1 -> 2 -> 3 -> 4
    }
}

Complexity: O(n) time, O(1) extra space.

Q2. Code a linked list that utilizes different functions (a general-purpose linked list class).
LeetCode: Related: Design Linked List ↗

Problem statement: Build a reusable, self-contained singly linked list CLASS supporting common operations: adding to the front, adding to the back, removing a value, checking whether a value is present, and getting the list's current size -- rather than working with loose LinkedListNode objects directly.

public class CustomLinkedList {
 
    private LinkedListNode headNode;
    private int listSize;
 
    // Adds a new value to the FRONT of the list
    public void addToFront(int newValue) {
        LinkedListNode newNode = new LinkedListNode(newValue);
        newNode.nextNode = headNode;
        headNode = newNode;
        listSize++;
    }
 
    // Adds a new value to the BACK of the list
    public void addToBack(int newValue) {
        LinkedListNode newNode = new LinkedListNode(newValue);
        if (headNode == null) {
            headNode = newNode;
        } else {
            LinkedListNode currentNode = headNode;
            while (currentNode.nextNode != null) {
                currentNode = currentNode.nextNode;
            }
            currentNode.nextNode = newNode;
        }
        listSize++;
    }
 
    // Removes the FIRST node matching targetValue, if present
    public boolean removeValue(int targetValue) {
        if (headNode == null) {
            return false;
        }
        if (headNode.nodeValue == targetValue) {
            headNode = headNode.nextNode;
            listSize--;
            return true;
        }
 
        LinkedListNode previousNode = headNode;
        LinkedListNode currentNode = headNode.nextNode;
        while (currentNode != null) {
            if (currentNode.nodeValue == targetValue) {
                previousNode.nextNode = currentNode.nextNode; // unlink currentNode
                listSize--;
                return true;
            }
            previousNode = currentNode;
            currentNode = currentNode.nextNode;
        }
        return false; // value not found
    }
 
    public boolean containsValue(int targetValue) {
        LinkedListNode currentNode = headNode;
        while (currentNode != null) {
            if (currentNode.nodeValue == targetValue) {
                return true;
            }
            currentNode = currentNode.nextNode;
        }
        return false;
    }
 
    public int getSize() {
        return listSize;
    }
 
    public static void main(String[] arguments) {
        CustomLinkedList myList = new CustomLinkedList();
        myList.addToBack(10);
        myList.addToBack(20);
        myList.addToFront(5);
        System.out.println(myList.containsValue(20)); // true
        myList.removeValue(20);
        System.out.println(myList.containsValue(20)); // false
        System.out.println(myList.getSize());          // 2
    }
}

Complexity: addToFront is O(1). addToBack, removeValue, and containsValue are each O(n), since they may need to walk the entire list.

Finding Specific Nodes

Q3. Find the middle node of a singly linked list.
LeetCode: Middle Of The Linked List ↗

Problem statement: Given the head of a singly linked list, return its MIDDLE node. If there are two middle nodes (an even-length list), return the SECOND of the two. Example: for the list 1 -> 2 -> 3 -> 4 -> 5, the middle node is 3.

Approach: the fast-and-slow pointer technique. Both pointers start at the head; slowPointer advances one node at a time, while fastPointer advances two nodes at a time. When fastPointer reaches the end, slowPointer -- having moved at half the speed -- is exactly at the middle.

public class MiddleNodeFinder {
 
    public static LinkedListNode findMiddleNode(LinkedListNode headNode) {
        LinkedListNode slowPointer = headNode;
        LinkedListNode fastPointer = headNode;
 
        while (fastPointer != null && fastPointer.nextNode != null) {
            slowPointer = slowPointer.nextNode;             // moves 1 step
            fastPointer = fastPointer.nextNode.nextNode;     // moves 2 steps
        }
        return slowPointer; // lands exactly on the middle once fastPointer reaches the end
    }
 
    public static void main(String[] arguments) {
        LinkedListNode headNode = new LinkedListNode(1);
        headNode.nextNode = new LinkedListNode(2);
        headNode.nextNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode.nextNode = new LinkedListNode(4);
        headNode.nextNode.nextNode.nextNode.nextNode = new LinkedListNode(5);
 
        LinkedListNode middleNode = findMiddleNode(headNode);
        System.out.println(middleNode.nodeValue); // 3
    }
}

Complexity: O(n) time (a single pass, since fastPointer visits every node at most once), O(1) extra space -- avoiding the need for a first pass just to count the list's total length.

Q4. Find the nth node from the end of a linked list. (Asked twice: "find nth node from the end" and "keep track of nth to last node.")
LeetCode: Remove Nth Node From End Of List ↗

Problem statement: Given the head of a singly linked list and an integer positionFromEnd, return the node that is positionFromEnd nodes from the END of the list (where positionFromEnd = 1 means the very last node). Example: for the list 1 -> 2 -> 3 -> 4 -> 5, findNthFromEnd(headNode, 2) should return the node with value 4.

Approach: the two-pointer "runner" technique. Advance a leadPointer positionFromEnd nodes ahead of a trailPointer first; then advance both pointers together, one step at a time, until leadPointer reaches the end. At that point, trailPointer is exactly positionFromEnd nodes from the end -- achieved in a SINGLE pass, without needing to know the list's length in advance.

public class NthFromEndFinder {
 
    public static LinkedListNode findNthFromEnd(LinkedListNode headNode, int positionFromEnd) {
        LinkedListNode leadPointer = headNode;
        LinkedListNode trailPointer = headNode;
 
        // advance leadPointer "positionFromEnd" nodes ahead of trailPointer
        for (int stepCount = 0; stepCount < positionFromEnd; stepCount++) {
            if (leadPointer == null) {
                throw new IllegalArgumentException("positionFromEnd exceeds the list's length");
            }
            leadPointer = leadPointer.nextNode;
        }
 
        // advance both pointers together until leadPointer reaches the end;
        // trailPointer is then exactly "positionFromEnd" nodes from the end
        while (leadPointer != null) {
            leadPointer = leadPointer.nextNode;
            trailPointer = trailPointer.nextNode;
        }
        return trailPointer;
    }
 
    public static void main(String[] arguments) {
        LinkedListNode headNode = new LinkedListNode(1);
        headNode.nextNode = new LinkedListNode(2);
        headNode.nextNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode.nextNode = new LinkedListNode(4);
        headNode.nextNode.nextNode.nextNode.nextNode = new LinkedListNode(5);
 
        LinkedListNode resultNode = findNthFromEnd(headNode, 2);
        System.out.println(resultNode.nodeValue); // 4
    }
}

Complexity: O(n) time (a single pass), O(1) extra space.

Reversal & Deduplication

Q5. Reverse a linked list. Given the list's head, return the new head of the reversed list.
LeetCode: Reverse Linked List ↗

Problem statement: Given the head of a singly linked list, reverse it in place and return the new head (which was previously the tail). Example: for the list 1 -> 2 -> 3 -> 4, the reversed list is 4 -> 3 -> 2 -> 1.

public class LinkedListReverser {
 
    public static LinkedListNode reverseList(LinkedListNode headNode) {
        LinkedListNode previousNode = null;
        LinkedListNode currentNode = headNode;
 
        while (currentNode != null) {
            LinkedListNode nextNode = currentNode.nextNode; // save before overwriting it
            currentNode.nextNode = previousNode;              // reverse this node's pointer
            previousNode = currentNode;                        // advance previousNode
            currentNode = nextNode;                             // advance currentNode
        }
        return previousNode; // previousNode ends up as the new head
    }
 
    public static void main(String[] arguments) {
        LinkedListNode headNode = new LinkedListNode(1);
        headNode.nextNode = new LinkedListNode(2);
        headNode.nextNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode.nextNode = new LinkedListNode(4);
 
        LinkedListNode reversedHead = reverseList(headNode);
        printList(reversedHead); // 4 -> 3 -> 2 -> 1
    }
 
    private static void printList(LinkedListNode headNode) {
        LinkedListNode currentNode = headNode;
        while (currentNode != null) {
            System.out.print(currentNode.nodeValue + (currentNode.nextNode != null ? " -> " : ""));
            currentNode = currentNode.nextNode;
        }
        System.out.println();
    }
}

Complexity: O(n) time (each node is visited exactly once), O(1) extra space.

Q6. Replace (remove) duplicates in a list.
LeetCode: Remove Duplicates From Sorted List ↗

Problem statement: Given the head of an UNSORTED singly linked list, remove every duplicate value, keeping only the FIRST occurrence of each distinct value. Example: for the list 1 -> 3 -> 2 -> 3 -> 1 -> 5, the result should be 1 -> 3 -> 2 -> 5.

import java.util.HashSet;
import java.util.Set;
 
public class DuplicateRemover {
 
    public static void removeDuplicateValues(LinkedListNode headNode) {
        if (headNode == null) {
            return;
        }
        Set<Integer> valuesSeenSoFar = new HashSet<>();
        LinkedListNode previousNode = headNode;
        valuesSeenSoFar.add(headNode.nodeValue);
 
        LinkedListNode currentNode = headNode.nextNode;
        while (currentNode != null) {
            if (valuesSeenSoFar.contains(currentNode.nodeValue)) {
                // duplicate value found -- unlink it by skipping over it
                previousNode.nextNode = currentNode.nextNode;
            } else {
                valuesSeenSoFar.add(currentNode.nodeValue);
                previousNode = currentNode; // only advance previousNode when we KEEP a node
            }
            currentNode = currentNode.nextNode;
        }
    }
 
    public static void main(String[] arguments) {
        LinkedListNode headNode = new LinkedListNode(1);
        headNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode = new LinkedListNode(2);
        headNode.nextNode.nextNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode.nextNode.nextNode = new LinkedListNode(1);
        headNode.nextNode.nextNode.nextNode.nextNode.nextNode = new LinkedListNode(5);
 
        removeDuplicateValues(headNode);
        printList(headNode); // 1 -> 3 -> 2 -> 5
    }
 
    private static void printList(LinkedListNode headNode) {
        LinkedListNode currentNode = headNode;
        while (currentNode != null) {
            System.out.print(currentNode.nodeValue + (currentNode.nextNode != null ? " -> " : ""));
            currentNode = currentNode.nextNode;
        }
        System.out.println();
    }
}
Note: If a HashSet is not allowed (e.g. the interviewer specifically asks for O(1) extra space), an alternative approach uses two nested pointers: for each node, walk the REST of the list ahead of it, removing any later node with the same value. This works without extra memory, but runs in O(n^2) time instead of O(n) -- a classic time/space tradeoff worth explicitly mentioning.

Complexity: O(n) time and O(n) extra space using a HashSet. O(n^2) time and O(1) extra space using the nested-pointer alternative.

Q7. In-memory node deletion from a linked list, given only a reference to the node to delete (not the head).
LeetCode: Delete Node In A Linked List ↗

Problem statement: Given a reference to a node WITHIN a singly linked list (but NOT a reference to the list's head, and assuming the node to delete is not the last node), delete that node from the list. Since you cannot access the PREVIOUS node (no back-pointer exists in a singly linked list, and you don't have the head to walk from), a different trick is required.

Approach: rather than truly deleting the given node, COPY the value from the NEXT node into it, then delete the NEXT node instead (which is easy, since you DO have direct access to it via nodeToDelete.nextNode). The list ends up with the same effective sequence of values, one node shorter.

public class InMemoryNodeDeleter {
 
    public static void deleteNodeGivenOnlyItself(LinkedListNode nodeToDelete) {
        if (nodeToDelete == null || nodeToDelete.nextNode == null) {
            throw new IllegalArgumentException("Cannot delete the last node using this technique");
        }
 
        LinkedListNode followingNode = nodeToDelete.nextNode;
 
        // overwrite THIS node's data with the NEXT node's data...
        nodeToDelete.nodeValue = followingNode.nodeValue;
        // ...then unlink the (now-duplicated) next node entirely
        nodeToDelete.nextNode = followingNode.nextNode;
    }
 
    public static void main(String[] arguments) {
        LinkedListNode headNode = new LinkedListNode(1);
        headNode.nextNode = new LinkedListNode(2);
        headNode.nextNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode.nextNode = new LinkedListNode(4);
 
        LinkedListNode nodeToDelete = headNode.nextNode; // the node holding value 2
        deleteNodeGivenOnlyItself(nodeToDelete);
 
        printList(headNode); // 1 -> 3 -> 4
    }
 
    private static void printList(LinkedListNode headNode) {
        LinkedListNode currentNode = headNode;
        while (currentNode != null) {
            System.out.print(currentNode.nodeValue + (currentNode.nextNode != null ? " -> " : ""));
            currentNode = currentNode.nextNode;
        }
        System.out.println();
    }
}

Complexity: O(1) time and space -- this technique is specifically valued for being much faster than the O(n) it would otherwise take to walk from the head to find the PREVIOUS node.

Cycle Detection & Structural Problems

Q8. Find a loop (cycle) in a linked list.
LeetCode: Linked List Cycle ↗

Problem statement: Given the head of a linked list, determine whether the list contains a CYCLE (i.e. some node's nextNode pointer eventually leads back to a PREVIOUSLY visited node, rather than eventually reaching null).

Approach: Floyd's Cycle Detection (the fast-and-slow pointer technique, also used above to find the middle node). If a cycle exists, the faster pointer will eventually "lap" the slower pointer and they will point to the SAME node at the SAME time.

public class LinkedListCycleDetector {
 
    public static boolean hasCycle(LinkedListNode headNode) {
        LinkedListNode slowPointer = headNode;
        LinkedListNode fastPointer = headNode;
 
        while (fastPointer != null && fastPointer.nextNode != null) {
            slowPointer = slowPointer.nextNode;
            fastPointer = fastPointer.nextNode.nextNode;
 
            if (slowPointer == fastPointer) {
                return true; // fastPointer has "lapped" slowPointer -- a cycle exists
            }
        }
        return false; // fastPointer reached null -- no cycle
    }
 
    public static void main(String[] arguments) {
        LinkedListNode headNode = new LinkedListNode(1);
        headNode.nextNode = new LinkedListNode(2);
        headNode.nextNode.nextNode = new LinkedListNode(3);
        headNode.nextNode.nextNode.nextNode = headNode.nextNode; // creates a cycle back to node 2
 
        System.out.println(hasCycle(headNode)); // true
    }
}

Complexity: O(n) time, O(1) extra space -- notably better than an alternative approach using a HashSet to track visited nodes, which would use O(n) extra space.

Q9. Given three linked list heads, find their common junction (where the lists merge).
LeetCode: Related: Intersection Of Two Linked Lists ↗

Problem statement: Given the heads of THREE singly linked lists that eventually MERGE into a single shared tail (like the letter Y, but with three branches), find the node at which all three lists first come together. This generalizes the classic two-list "intersection" problem.

Approach: solve the two-list version first (align both lists' starting points by first walking off the LENGTH DIFFERENCE between them, then advance both pointers together until they point to the SAME node), then apply it pairwise: find the junction of lists 1 and 2, then find the junction of THAT result and list 3.

public class CommonJunctionFinder {
 
    // Finds the node where two lists first merge together (classic two-list version)
    public static LinkedListNode findJunctionOfTwoLists(LinkedListNode firstHead, LinkedListNode secondHead) {
        int firstLength = calculateListLength(firstHead);
        int secondLength = calculateListLength(secondHead);
 
        LinkedListNode longerListPointer = firstLength >= secondLength ? firstHead : secondHead;
        LinkedListNode shorterListPointer = firstLength >= secondLength ? secondHead : firstHead;
 
        // advance the pointer on the LONGER list first, to align both
        // pointers the same distance from the eventual junction
        int lengthDifference = Math.abs(firstLength - secondLength);
        for (int stepCount = 0; stepCount < lengthDifference; stepCount++) {
            longerListPointer = longerListPointer.nextNode;
        }
 
        // advance both pointers together -- they will meet exactly at the junction
        while (longerListPointer != shorterListPointer) {
            longerListPointer = longerListPointer.nextNode;
            shorterListPointer = shorterListPointer.nextNode;
        }
        return longerListPointer; // could also be null, if the lists never actually merge
    }
 
    // Generalizes to THREE lists by finding the junction pairwise
    public static LinkedListNode findJunctionOfThreeLists(LinkedListNode firstHead,
                                                            LinkedListNode secondHead,
                                                            LinkedListNode thirdHead) {
        LinkedListNode junctionOfFirstTwo = findJunctionOfTwoLists(firstHead, secondHead);
        return findJunctionOfTwoLists(junctionOfFirstTwo, thirdHead);
    }
 
    private static int calculateListLength(LinkedListNode headNode) {
        int lengthCount = 0;
        LinkedListNode currentNode = headNode;
        while (currentNode != null) {
            lengthCount++;
            currentNode = currentNode.nextNode;
        }
        return lengthCount;
    }
}

Complexity: O(n + m + k) time, where n, m, and k are the lengths of the three lists -- each list is walked a small, constant number of times. O(1) extra space.

Q10. Flatten a multilevel linked list (each node may have a child pointer to a separate sub-list).
LeetCode: Flatten A Multilevel Doubly Linked List ↗

Problem statement: Given a linked list where, in addition to the usual nextNode pointer, some nodes also have a childNode pointer to the head of a SEPARATE, independent sub-list, "flatten" the entire structure into a single-level linked list. Whenever a node with a child is encountered, its entire child list (which may itself contain further nested children) should be spliced in immediately after that node, before continuing with what was originally its next node.

public class MultilevelLinkedListNode {
    int nodeValue;
    MultilevelLinkedListNode nextNode;
    MultilevelLinkedListNode childNode; // may be null, or point to a nested sub-list
 
    MultilevelLinkedListNode(int nodeValue) {
        this.nodeValue = nodeValue;
    }
}
 
public class MultilevelListFlattener {
 
    public static MultilevelLinkedListNode flattenMultilevelList(MultilevelLinkedListNode headNode) {
        MultilevelLinkedListNode currentNode = headNode;
 
        while (currentNode != null) {
            if (currentNode.childNode != null) {
                MultilevelLinkedListNode nextSiblingNode = currentNode.nextNode;
 
                // recursively flatten the child list first, in case IT also
                // has further nested children
                MultilevelLinkedListNode flattenedChildHead = flattenMultilevelList(currentNode.childNode);
 
                // splice the (now fully flattened) child list in right after currentNode
                currentNode.nextNode = flattenedChildHead;
                currentNode.childNode = null; // this level no longer has an unflattened child
 
                // find the END of the just-spliced-in child list, to reconnect
                // it to what was originally currentNode's next sibling
                MultilevelLinkedListNode tailOfChildList = flattenedChildHead;
                while (tailOfChildList.nextNode != null) {
                    tailOfChildList = tailOfChildList.nextNode;
                }
                tailOfChildList.nextNode = nextSiblingNode;
            }
            currentNode = currentNode.nextNode;
        }
        return headNode;
    }
}

Complexity: O(n) time overall -- although finding the tail of each spliced-in child list involves an extra walk, every node in the entire structure is still visited only a small, bounded number of times in total. O(d) extra space for the recursive call stack, where d is the maximum nesting depth of child lists.

Implementing a Deque with a Doubly Linked List

Q11. Implement a Deque, with some follow-up on optimization (solved with a doubly linked list).
LeetCode: Related: Design Circular Deque ↗

Problem statement: Implement a Deque (double-ended queue) supporting O(1) insertion and removal at BOTH the front and the back, from scratch, using a doubly linked list (rather than relying on Java's own built-in ArrayDeque).

Approach: a doubly linked list -- where each node holds both a nextNode AND a previousNode pointer -- naturally supports O(1) operations at both ends, since no shifting of other elements is ever required (unlike an array-backed implementation, where removing from the front would require shifting every remaining element).

public class DoublyLinkedListNode {
    int nodeValue;
    DoublyLinkedListNode nextNode;
    DoublyLinkedListNode previousNode;
 
    DoublyLinkedListNode(int nodeValue) {
        this.nodeValue = nodeValue;
    }
}
 
public class CustomDeque {
 
    private DoublyLinkedListNode frontNode;
    private DoublyLinkedListNode backNode;
    private int elementCount;
 
    public void addToFront(int newValue) {
        DoublyLinkedListNode newNode = new DoublyLinkedListNode(newValue);
        if (frontNode == null) {
            frontNode = newNode;
            backNode = newNode;
        } else {
            newNode.nextNode = frontNode;
            frontNode.previousNode = newNode;
            frontNode = newNode;
        }
        elementCount++;
    }
 
    public void addToBack(int newValue) {
        DoublyLinkedListNode newNode = new DoublyLinkedListNode(newValue);
        if (backNode == null) {
            frontNode = newNode;
            backNode = newNode;
        } else {
            newNode.previousNode = backNode;
            backNode.nextNode = newNode;
            backNode = newNode;
        }
        elementCount++;
    }
 
    public int removeFromFront() {
        if (frontNode == null) {
            throw new IllegalStateException("Cannot remove from an empty deque");
        }
        int removedValue = frontNode.nodeValue;
        frontNode = frontNode.nextNode;
 
        if (frontNode != null) {
            frontNode.previousNode = null;
        } else {
            backNode = null; // the deque is now empty
        }
        elementCount--;
        return removedValue;
    }
 
    public int removeFromBack() {
        if (backNode == null) {
            throw new IllegalStateException("Cannot remove from an empty deque");
        }
        int removedValue = backNode.nodeValue;
        backNode = backNode.previousNode;
 
        if (backNode != null) {
            backNode.nextNode = null;
        } else {
            frontNode = null; // the deque is now empty
        }
        elementCount--;
        return removedValue;
    }
 
    public int getSize() {
        return elementCount;
    }
 
    public static void main(String[] arguments) {
        CustomDeque myDeque = new CustomDeque();
        myDeque.addToBack(1);
        myDeque.addToBack(2);
        myDeque.addToFront(0);
        // deque now holds: 0, 1, 2
 
        System.out.println(myDeque.removeFromFront()); // 0
        System.out.println(myDeque.removeFromBack());   // 2
        System.out.println(myDeque.getSize());           // 1
    }
}
Note: The KEY optimization a doubly linked list provides over a SINGLY linked list here is the previousNode pointer -- without it, removeFromBack() would require walking the ENTIRE list from the front just to find the second-to-last node (to become the new back), costing O(n) instead of O(1). Maintaining backNode AND the previousNode chain is precisely what makes BOTH ends of the deque equally fast to operate on.

Complexity: O(1) time for every operation (addToFront, addToBack, removeFromFront, removeFromBack), O(1) extra space per operation (O(n) total space to store n elements).
